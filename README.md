# usage-monitor

Mod for Claude Code (desktop app). Shows, per chat, in a pane and in the status line:

- account rate limits (5h / 7d) with a live countdown and the reset day (PL)
- context window fill
- prompt-cache hit rate
- session cost

## Install

In the desktop app: **+** next to the prompt box -> Plugins -> **+** -> Add from a repository -> `tatkoklkl-coder/usage-monitor`, then add the `usage-monitor` plugin.

Open the pane with `/usage-monitor`.
